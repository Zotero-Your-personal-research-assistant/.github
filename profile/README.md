# Project Overview

Zotero is a free and open-source reference management application designed to help users collect, organize, cite, and manage research materials. It can store bibliographic information, documents, notes, attachments, and related research data in a centralized library.

The application is useful for students, researchers, academics, writers, and anyone working with large collections of sources. Users can organize references into collections, add tags, search their library, attach files, and manage bibliographic metadata.

Zotero also integrates with supported word-processing applications, allowing users to insert citations and automatically generate bibliographies while writing documents.

---

# Reference Management & Research Library

Zotero provides tools for collecting and organizing references from books, journal articles, websites, reports, and other research sources.

References can be organized into collections and subcollections, while tags and search tools help users locate specific sources within larger libraries.

Bibliographic information can include titles, authors, publication dates, publishers, journal information, identifiers, and other metadata. Users can review and edit metadata when imported information requires correction.

Attachments such as PDFs and other supported files can be associated with individual references, keeping source material together with its bibliographic record.

---

# Citations & Bibliographies

Zotero integrates with supported word processors to provide citation and bibliography tools.

Users can insert references directly into documents and select from supported citation styles. Bibliographies can then be generated automatically from the references used in a document.

Citation styles can be changed when required, allowing the same research library to be used across different academic or publishing requirements.

Zotero's citation workflow can reduce repetitive manual formatting when working with documents containing many references.

---

# Notes, Tags & Collaboration

Zotero provides tools for creating notes associated with individual references or research collections. Notes can be used to record summaries, ideas, observations, or other information related to a source.

Tags can be assigned to references to provide an additional organizational layer. Search and filtering features make it easier to locate materials based on metadata and organizational information.

Zotero also provides synchronization and collaboration capabilities through Zotero accounts and supported online services. Synchronization settings should be configured according to the user's storage and collaboration requirements.

---

# Browser Integration & Extensions

Zotero can work with browser-based workflows through its supported browser connector, allowing users to save bibliographic information from compatible websites and databases.

The application can automatically retrieve available metadata from supported sources, after which users can review and correct the imported information.

Additional functionality can be provided through Zotero plugins and extensions. Third-party extensions should be obtained from trusted sources and checked for compatibility with the installed Zotero version.

---

# System Compatibility & Performance

Zotero is available for modern Windows, macOS, and Linux systems. Basic reference management requires relatively modest hardware, while very large libraries and extensive attachment collections can require additional storage and memory.

| Component        | Minimum Practical Configuration                                          |
| ---------------- | ------------------------------------------------------------------------ |
| Operating System | Windows 10 / Windows 11, supported macOS, or Linux                       |
| Processor        | Modern dual-core CPU                                                     |
| Memory           | 2 GB RAM minimum; 4 GB+ recommended                                      |
| Storage          | 500 MB+ for the application plus space for attachments                   |
| Graphics         | Integrated graphics supported                                            |
| Display          | 1024×768 or higher                                                       |
| Architecture     | 64-bit recommended                                                       |
| Internet         | Optional for local use; required for synchronization and online features |

These specifications represent a practical configuration rather than guaranteed requirements for every Zotero workflow. Large research libraries, numerous PDF attachments, synchronization, and multiple applications running simultaneously can increase resource requirements.

Additional storage may be necessary when maintaining large collections of locally stored research papers and other attachments.
